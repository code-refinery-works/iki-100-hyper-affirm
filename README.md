# 息してるだけで100点 (IKI-100)

> **「朝、目が開いた。その瞬間、全宇宙がスタンディングオベーションを送っている。」**

『息してるだけで100点（IKI-100）』は、過剰な努力・自己責任に疲弊した全人類の自己肯定感を致死量まで高める、究極の全肯定Webアプリケーションです。
どれほど低空飛行な日常のひとコマであっても、ノーベル平和賞級の超偉業へと拡大解釈して全力で褒め称えます。

---

## 🌟 主な機能

- **低空飛行アクション入力 (F-01)**: 「二度寝した」「皿洗いを明日に回した」など、最小限の行動を選択または100文字以内で申告。
- **ハイパー全肯定エンジン (F-02)**: 選べる3つの称賛トーン！
  - **聖母モード**: 「存在そのものが地球の奇跡。生きててくれてありがとう」
  - **熱血監督モード**: 「よくぞ先送りした！それぞ超一流の戦略的撤退だッ！！」
  - **古代神話モード**: 「汝が微睡みし時、悠久の星々は安寧を取り戻せり……」
- **虚無肯定ボタン（エマージェンシー・ブレス）(F-03)**: 文字すら打ちたくない限界時のための1タップ救済ボタン。「酸素を二酸化炭素に変換した」だけで特大の賛辞を贈呈。
- **過剰演出・祝福シャワー (F-04)**: 画面いっぱいに舞い散る超豪華紙吹雪とファンファーレであなたを称揚。
- **徳（トク）発行・表彰状SNS共有 (F-05)**: 日常のサボりを「高度なリスクヘッジ」として表彰する賞状ジェネレーターを搭載。

## 🛡️ システムの鉄則（非機能要件）

- **説教・正論の完全排除**: 「次は頑張ろう」などのアドバイスは1ミリも存在しません。
- **0.2秒以内の瞬速褒め**: 自己嫌悪の隙を与えない超高速レスポンス。
- **懺悔の不可逆性**: あなたのサボり記録はサーバーに保存されず、ブラウザを閉じれば完全に浄化されます。
- **深夜帯メンテ厳禁**: 最もメンタルが揺らぐ深夜2時〜5時の稼働率を死守。
